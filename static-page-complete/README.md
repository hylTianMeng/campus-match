# CampusCrew 完整静态原型

此目录独立于 `../static-page/`，保留原交付包的文件结构和内容。直接在浏览器打开 [`dist/index.html`](dist/index.html) 即可体验，无需安装依赖。页面使用浏览器本地演示状态，不连接后端。

页面覆盖范围和走查路径见 [功能覆盖与走查](功能覆盖与走查.md)。

## 本次补充

发布招募时可选填联系方式、赛事或活动介绍、导师介绍、预期成果、活动链接及附件说明；申请岗位时可选填留言、相关经历和简历或作品链接。未填写的招募补充信息不会占用详情页空间。公开详情只展示申请中人数，申请资料仅在发布者演示身份的申请管理页与申请者自己的记录中展示；个人公开主页不展示申请记录。

本目录是无后端的本机静态原型。评审身份切换和页面路由限制只用于演示，浏览器本地状态不能作为真实权限隔离。正式上线必须由服务端验证当前用户是否为该招募发布者，并只向有权限的用户返回申请资料；简历文件存储与授权下载也需由服务端实现。
