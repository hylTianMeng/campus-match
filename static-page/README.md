# CampusCrew 校园组队静态网站

清华紫、米白留白、宋体标题与清华园建筑线稿构成的校园网站原型。面向电脑浏览器制作，同时适配手机窄屏。

## 启动

需要 Node.js，无需安装依赖。

```sh
cd static-page
npm start
```

从仓库根目录进入 `static-page` 后运行命令，浏览器打开 http://127.0.0.1:4173。也可直接打开本目录的 `index.html` 浏览；推荐通过本地服务运行，以保证浏览器存储和注册体验一致。

```sh
npm run check
npm test
```

## 体验流程

登录页可以直接点击两个体验账号，也可填写示例邮箱及密码 `campus123`：

- 林知夏 `lin@example.edu`：已发布校园组队平台招募，可审核周予安、陈以宁的申请。
- 周予安 `zhou@example.edu`：同一招募的两个岗位处于待审，可以查看录取后的自动撤回及组队历史。
- 注册页可新建本地演示账号；演示验证码为 `123456`，不发送真实邮件，不校验真实校园身份。请勿填写真实密码。

推荐先以林知夏审核设计岗位的周予安申请：其后端申请自动撤回，其他设计申请因满员未通过。再切到周予安，在通知与我的申请中查看结果。也可新建单岗位一名的招募，切换账号申请，再审核最后名额，观察满员结束与结果锁定。

支持手动草稿、已发布受限编辑、条件删除、提前结束、申请及重申请、撤回、撤销/放弃录取、名额联动、收藏、资料和头像修改、本地未读通知。数据存入当前浏览器；页面底部“恢复初始演示”可重置本地演示数据。

发布招募时，可选填联系方式、赛事或活动介绍、导师介绍、预期成果、附件说明与链接、活动页面链接。申请岗位时，可选填留言、相关经历、可投入时间、联系方式、简历链接和作品集链接。没有填写的补充项不会占据详情页空间。公开页面显示待审核的申请人数，不展示申请者资料；申请者本人可在“我的申请”回看，招募者可在“申请管理”查看。附件和简历通过 `http` 或 `https` 链接提供。

## 范围与限制

实现依据见 [核心页面说明](../doc/05-core-pages-and-functions.md)。本项目为纯静态交互原型，没有服务端、真实鉴权、真实邮件、多人共享数据或并发事务保证；账号与操作守卫仅供演示，不能用于生产权限控制。未接入私信和管理后台。

申请者资料虽然在界面上只向本人及招募者展示，仍以明文保存在当前浏览器的 `localStorage` 中。若要满足真实的“其他人不可见”，需接入后端身份认证、按招募所有者授权的接口与服务端存储；请勿在本地演示中填写真实敏感资料。

手动结束时待审申请的终态尚未确认，原型保留记录并锁定操作，不擅自标记过期。所有岗位满员后立即结束，无候补或七天确认期；已结束结果不能撤销。个人中心只显示保持通过结果的组队记录，不建设长期团队空间。

## 文件

- `index.html`：入口。
- `styles.css`：清华风格及响应式布局，无第三方字体或图片依赖。
- `app.js`：示例数据、本地存储、页面渲染及交互。
- `server.mjs`：仅提供原型公开文件的本地预览服务。
- `tests/prototype.test.mjs`：核心申请状态联动验证。

视觉使用校园主题及原创线稿，不使用清华大学官方校徽，不表示官方服务。
